Data Tools

In the Data Tools chapter, I've learned about computing basic data sets and organizing and noticing patterns in the data. First off in this chapter I learned how to store data sets. Text files could be one way data can be stored. If you want to store data into a text file with multiple columns you can use a CSV. You can also use a spreadsheet, a pretty often used application to store data. You can also use a database that many use to store data. In this chapter we also learned about computing data. The first question we can ask is how much data is there? We need to find out how much data is stored and that we will be analyizing. Another question is what is the largest and smallest data in each column of data and how many columns will be using. We can also ask what is the total value in each column. We also need to filter the data and use only what we need to. If we need to analyze a group of data and not just a single set of data, we can view a summary of each data statistics. I also learned how to recognize certain patterns in data and see if there is any trends.
