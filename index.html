My Final Project

My final Project was data analysis. My goal was to analyze a big set of data in order to achive my end goal.

My Data Set and Question

The data set I decided to analyze is data about crime in LA from 2020 to Present. The data included a lot of information including the area in which the crime was commitied, victim sex, the crime commited, the address of the crime, and wepon used and a lot more. My question was, which area had the most crime in LA.

The process

The data set was very large. There were over 986,874 rows. I decided to use microsoft Excel as my data analysis tool as it was the most accesable for me and the easiest. First looking at the data I was overwhelmed. I didn't know where to start. The good thing about this data is that they not only had the names of the area in La the crime was committed but they also had a seperate column numbering the area. So each area had its own number. I sorted the data from the area number ranging from 1-21 from least to greatest. The next step was challenging as I had to find a function that is able to count how many of each number there were. I stumbled across the count if function that counts a number if it is repeated and displays the result. To organize my work I went to the bottom of the graph. The column with the area number I used the function on. I set the number to number 1 and put a range of 2 through 986,874. The function counted all the results for me. On the right column I displayed the area code I was counting for so I knew what area it is that the count was for. I did that all the way through 21 times. It did not take long. I also deleted some columns with data that didn't matter. The columns I deleted had numbers 1-21 that wasn't the Area column. I figured out if the column did have those numbers by using the filters. The columns I deleted didn't matter to my progress in answering my question so there was no need for them. I than made a different spreadsheet using LibreOffice and listed the city and the number of crimes commited. I than made a graph with the y axis being the number of crimes and the x axis being the cities. I made this graph so it was more clear to see the data I have collected. I'm sure if the city of crime was for a much larger city or for a whole state my method would be time consuming. I would have to use a piviot table to seperate the data so I can find the answer and ccalculate the numbers more quickly or even use a different method.
